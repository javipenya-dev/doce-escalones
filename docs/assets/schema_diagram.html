🔗 Relaciones principales

alumnos──1:N──▶packs_alumno— Un alumno puede tener varios packs activos
alumnos──N:M──▶hermanos— Relación simétrica entre alumnos
packs_alumno──N:1──▶tarifas— Cada pack usa una tarifa base
packs_alumno──N:1──▶usuarios— Profesor asignado al pack
asistencias──N:1──▶packs_alumno— Cada asistencia descuenta del pack correcto
asistencias──N:1──▶usuarios— Profesor que imparte
cobros──1:N──▶cobros_pagos— Un cobro puede tener varios métodos de pago
cobros──1:N──▶cobros_packs— Un cobro puede cubrir varios packs
cobros──1:1──▶facturas— Factura opcional por cobro
resumen_mensual──N:1──▶packs_alumno— Cache de horas/sesiones por mes y pack
tarifas──N:1──▶tipos_clase— Cada tarifa es de un tipo de clase
horas_profesor_mensual── VIEW ──asistencias— Calculado automáticamente
